# GSM Project Glossary / لغت‌نامه پروژه GSM

---

## A

| English | فارسی | Description / توضیح |
|---------|-------|---------------------|
| **AEO** | بهینه‌سازی موتور پاسخ | Answer Engine Optimization - بهینه‌سازی محتوا برای تبدیل شدن به منبع پاسخ AI |
| **Admin Panel** | پنل مدیریت | بخش مدیریت سایت برای ادمین و ویرایشگر |
| **API Route** | مسیر API | Endpoint‌های سمت سرور Next.js در مسیر `/api/*` |
| **Article** | مقاله | نوع محتوای تحلیلی و بلند |
| **ArticleTag** | تگ مقاله | جدول واسط ارتباط چند‌به‌چند مقاله و تگ |
| **Auth / Authentication** | احراز هویت | فرآیند ورود و شناسایی کاربر |
| **Author** | نویسنده | شخصی که مقاله/خبر می‌نویسد |
| **Avatar** | آواتار | تصویر پروفایل نویسنده |

## Status Values / مقادیر وضعیت

### ContentStatus
| Value | فارسی | Description |
|-------|-------|-------------|
| `DRAFT` | پیش‌نویس | مقاله هنوز منتشر نشده |
| `PUBLISHED` | منتشر شده | مقاله عمومی و قابل مشاهده |

### PostType
| Value | فارسی | Description |
|-------|-------|-------------|
| `NEWS` | اخبار | محتوای خبری کوتاه |
| `ARTICLE` | مقاله | محتوای تحلیلی بلند |
| `REVIEW` | بررسی | بررسی تخصصی محصول |
| `STORY` | استوری | محتوای کوتاه تصویری |

### UserRole
| Value | فارسی | Description |
|-------|-------|-------------|
| `ADMIN` | مدیر | دسترسی کامل به تمام بخش‌ها |
| `EDITOR` | ویرایشگر | دسترسی به مدیریت محتوا |

### ImportRunStatus
| Value | فارسی | Description |
|-------|-------|-------------|
| `PENDING` | در انتظار | درون‌ریزی ایجاد شده ولی شروع نشده |
| `RUNNING` | در حال اجرا | درون‌ریزی در حال انجام |
| `COMPLETED` | تکمیل شده | درون‌ریزی با موفقیت پایان یافت |
| `FAILED` | ناموفق | درون‌ریزی با خطا متوقف شد |
